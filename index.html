GPT-2, rebuilt in Go.
Taught to decide.

We rebuilt GPT-2's architecture layer by layer in Go, each layer following the paper that introduced it. Then we changed it in five places and trained it on decisions. Golem-One XL answers typed questions with a probability for every allowed answer. It answers them all in one pass, and it can't give an answer that wasn't offered.

The idea in ten seconds

Stop generating answers. Score them.

A token-by-token model decides by writing: one full pass per token, 50,257 candidates each time, and nothing stops it writing an answer that isn't on the list. Golem-One reads the same network differently.

03
Decide

How one pass answers every question.

The segment mask

Read the state once. Answer the questions in parallel.

Every question sees the whole state and its own tokens, never another question. Each result equals a separate forward pass, to 10⁻⁴. Hover or tap a row.

statequestion 1question 2question 3row = token that looks
column = token looked at
The restricted readout

Score only the K declared answers.

At each question's Answer: slot, only the tied-embedding rows of its option labels are scored and renormalized:

p(k) = exp(eℓₖᵀ h / T)Σj≤K exp(eℓⱼᵀ h / T)   c = 1 − H(p)/log K

That is K dot products instead of 50,257. T is fitted on held-out data: it changes how sure the model says it is, never which answer it picks.

Valid by construction. Only the declared options have any probability, so whatever the weights are, the model can't produce an answer that wasn't offered. Training makes the answers correct; the construction already makes them valid.

Not evaluated yet
Accuracy, calibration and results on held-out task families come when training finishes. For now there are only training losses.

      
Valid isn't correct
Every answer is one of the declared options, but a confident wrong answer is still possible. Low-confidence answers should go to a person.

      
A research model
English only, with biases from GPT-2's web data and the labeled datasets. It's not for consequential decisions about people.
